# Приём заявок в Telegram

Форма «Записаться на приём» отправляет заявку в `lead.php`, а он пересылает её
ботом [@amirDentBot](https://t.me/amirDentBot) в Telegram.

```
браузер (форма)  ──POST /api/lead.php──▶  хостинг  ──sendMessage──▶  Telegram
                                          (config.php: токен, chat_id)
```

Токен бота лежит только в `config.php` на сервере. В файлы сайта его писать нельзя:
их исходники видны любому посетителю, и бота сразу угонят.

## Установка на хостинг

1. Загрузить папку `api` в корень сайта — туда, где лежит `index.html`.
   Должно получиться `amirdent.ru/api/lead.php`.

2. Рядом с `lead.php` создать `config.php` по образцу `config.example.php`:

   ```php
   <?php
   return [
       'bot_token' => 'токен от @BotFather',
       'chat_id' => '1424701831',
   ];
   ```

   Файл `config.php` в репозиторий не попадает (он в `.gitignore`) — заполняется
   один раз прямо на хостинге через файловый менеджер или по FTP.

3. Проверить, что заявки доходят: открыть сайт, заполнить форму, нажать
   «Записаться на приём». В Telegram должна прийти заявка, а на странице —
   «Заявка принята».

Больше ничего настраивать не нужно: адрес `/api/lead.php` уже прописан в
`assets/main.js`, а Telegram сам доставляет сообщения боту.

## Как узнать chat_id

Написать боту `/start`, затем открыть в браузере

```
https://api.telegram.org/bot<ТОКЕН>/getUpdates
```

и взять значение `result[0].message.chat.id`.

Чтобы заявки видели несколько администраторов, можно создать группу, добавить
в неё бота и указать в `chat_id` идентификатор группы (он начинается с `-100`).

## Что делает скрипт

- принимает только POST с JSON, остальное отклоняет
- проверяет имя (от 2 символов) и телефон (не меньше 10 цифр)
- ограничивает частоту: не больше 5 заявок за 10 минут с одного IP
- отбрасывает спам-ботов по скрытому полю `company` в форме
- экранирует данные перед отправкой в Telegram
- если Telegram недоступен, пишет заявку в `leads-failed.log`, чтобы её можно было
  найти вручную; посетителю форма в этот момент предлагает WhatsApp и телефон

Файл `.htaccess` закрывает от посторонних `config.php` и логи.

## Требования к хостингу

PHP 8.0 и новее с расширением cURL — есть на любом современном хостинге.
Проверить версию можно в панели управления хостингом.
