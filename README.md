# Сайт клиники АмирДент

Одностраничный сайт стоматологии на Яхромской: [amirdent.ru](https://amirdent.ru).
Обычные HTML, CSS и JavaScript без сборки — файлы работают как есть.
Заявки с формы записи приходят в Telegram, за это отвечает `api/lead.php`.

## Запустить у себя на компьютере

```bash
git clone https://github.com/DmitryStuzhin/AmirDent.git
cd AmirDent
./serve.sh
```

Открыть <http://localhost:8123>. Остановить — `Ctrl+C`.

Нужен PHP 7.4 и новее (`brew install php` на Mac) — он обслуживает отправку
заявок. Другой порт: `PORT=9000 ./serve.sh`. На Windows вместо `./serve.sh`:
`php -S localhost:8123 -t .`

Настраивать ничего не нужно: `api/config.php` с токеном бота лежит в
репозитории, поэтому заявки с любой машины разработчика доходят до Telegram.

**Поэтому репозиторий обязан оставаться приватным.** Если понадобится открыть
его публично, сначала отозвать токен в `@BotFather` (`/revoke`) и завести новый:
из истории git токен не удаляется и остаётся доступен по старым коммитам.

## Что где лежит

| Файл                    | Назначение                                          |
| ----------------------- | --------------------------------------------------- |
| `index.html`            | вся страница: услуги, цены, врачи, отзывы, форма     |
| `assets/styles.css`     | оформление                                          |
| `assets/main.js`        | меню, фильтр цен, галерея, отправка формы записи     |
| `api/lead.php`          | приём заявки и отправка её ботом в Telegram          |
| `api/config.php`        | токен бота и chat_id — пока репозиторий приватный, лежит здесь |
| `404.html`              | страница «не найдено»                               |
| `robots.txt`, `sitemap.xml` | для поисковых систем                             |

Как заявки попадают в Telegram и как выложить всё на хостинг — в
[api/README.md](api/README.md).

## Проверить, что заявки работают

Запустить сайт локально, заполнить форму в блоке «Записаться онлайн» и нажать
«Записаться на приём». Ожидаемо: под кнопкой появляется «Заявка принята», поля
очищаются, а в Telegram приходит заявка с именем, телефоном, услугой и временем.

Если вместо этого появилось красное сообщение со ссылкой на WhatsApp — заявка не
ушла. Причины по порядку: токен в `api/config.php` отозван, страница открыта как
файл (`file://`) вместо `localhost`, нет интернета.
Подробности пишутся в `api/leads-failed.log`, там же лежит сама заявка, чтобы её
не потерять.
