# Сайт клиники АмирДент

Одностраничный сайт стоматологии на Яхромской.
Обычные HTML, CSS и JavaScript без сборки — файлы работают как есть.
Заявки с формы записи приходят в Telegram, за это отвечает функция
`netlify/functions/lead.mjs`.

Хостинг — Netlify: [amirdent.netlify.app](https://amirdent.netlify.app).

## Запустить у себя на компьютере

```bash
git clone https://github.com/DmitryStuzhin/AmirDent.git
cd AmirDent
npm install
./serve.sh
```

Открыть <http://localhost:8123>. Остановить — `Ctrl+C`. Другой порт:
`PORT=9000 ./serve.sh`.

Поднимаются и страницы, и приём заявок — то же поведение, что на сайте. Нужен
Node.js **20.12.2 или новее**: на более старых версиях функция не запускается и
форма локально показывает отказ (на самом сайте это не влияет).

Настраивать ничего не нужно: токен бота лежит в `netlify/functions/settings.mjs`,
поэтому заявки с любой машины разработчика доходят до Telegram.

**Поэтому репозиторий обязан оставаться приватным.** Если понадобится открыть
его публично, сначала отозвать токен в `@BotFather` (`/revoke`) и завести новый:
из истории git токен не удаляется и остаётся доступен по старым коммитам.

## Что где лежит

| Файл                             | Назначение                                       |
| -------------------------------- | ------------------------------------------------ |
| `index.html`                     | вся страница: услуги, цены, врачи, отзывы, форма  |
| `assets/styles.css`              | оформление                                       |
| `assets/main.js`                 | меню, фильтр цен, галерея, отправка формы записи  |
| `netlify/functions/lead.mjs`     | приём заявки и отправка её ботом в Telegram       |
| `netlify/functions/settings.mjs` | токен бота и chat_id                              |
| `netlify.toml`                   | настройки Netlify: что публиковать, адрес функции |
| `404.html`                       | страница «не найдено»                            |
| `robots.txt`, `sitemap.xml`      | для поисковых систем                             |

Как заявки попадают в Telegram и как выложить сайт — в
[netlify/README.md](netlify/README.md).

## Проверить, что заявки работают

Запустить сайт локально, заполнить форму в блоке «Записаться онлайн» и нажать
«Записаться на приём». Ожидаемо: под кнопкой появляется «Заявка принята», поля
очищаются, а в Telegram приходит заявка с именем, телефоном, услугой и временем.

Если вместо этого появилось красное сообщение со ссылкой на WhatsApp — заявка не
ушла. Причины по порядку: Node.js старее 20.12.2, страница открыта как файл
(`file://`) вместо `localhost`, токен отозван, нет интернета. На сайте причину
видно в Netlify → Logs → Functions.
