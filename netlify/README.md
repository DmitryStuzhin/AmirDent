# Эксплуатация AmirDent на Netlify

## Переменные окружения

В Netlify → Site configuration → Environment variables должны быть заданы:

| Переменная | Назначение |
| --- | --- |
| `BOT_TOKEN` | актуальный токен Telegram-бота |
| `CHAT_ID` | получатель уведомлений |
| `CMS_LOGIN` | логин администратора без значения по умолчанию |
| `CMS_PASSWORD_HASH` | SHA-256 случайного пароля длиной от 20 символов |

Секреты никогда не записываются в файлы проекта. После любого раскрытия токен
сначала отзывается у провайдера, затем заменяется в Netlify; очистка Git-истории
сама по себе секрет не обезвреживает.

## Публикация

Основной вариант — merge проверенного изменения в `main`, если Netlify связан с
GitHub. Ручная публикация:

```bash
npm ci
npm run build
npm run check
npm run deploy
```

Перетаскивание папки в Netlify запрещено: так функции CMS и заявок не
публикуются.

## Контроль после релиза

1. `/api/health` отвечает `200` и показывает три успешные проверки.
2. Главная, `/prices`, одна страница `/uslugi/...`, `/privacy`, `/legal` открываются.
3. Неизвестная услуга возвращает 404.
4. Тестовая заявка сохраняется и приходит в Telegram.
5. Администратор входит, меняет тестовый текст, загружает фото, сохраняет и
   возвращает текст обратно.
6. На ширинах 320 и 390 px нет горизонтальной прокрутки.

## CMS

Авторизация использует серверную HttpOnly-cookie на восемь часов. После пяти
неверных попыток IP временно блокируется. Хеш пароля не хранится в браузере.
Каждое сохранение архивирует предыдущую версию в Netlify Blobs и проверяет
ревизию, поэтому одновременная работа двух редакторов не приводит к тихой
перезаписи.

Фотография уменьшается в браузере, очищается от EXIF при перерисовке, проверяется
по сигнатуре и сохраняется отдельно. Карточка не должна сохраняться, пока
загрузка не завершена.

## Заявки

`POST /api/lead` требует явного согласия, валидирует и нормализует телефон,
ограничивает частоту запросов и сохраняет заявку в хранилище `leads`. Telegram —
канал уведомления, а не единственная копия заявки. В логах нет имени и телефона.

## Откат

Для кода используйте Netlify Deploys → нужный успешный deploy → Publish deploy.
Перед крупным изменением контента выгрузите JSON из `/api/cms/content`.
При проблеме с заявками не отключайте форму: проверьте хранилище `leads`, журналы
функции и токен, затем выполните контрольную отправку.
